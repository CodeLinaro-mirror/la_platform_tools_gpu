# config
--
    import "android.googlesource.com/platform/tools/gpu/config"

Package config contains a list of build configuration flags.

## Usage

```go
const (
	DebugAtom           = false
	DebugDatabase       = false
	DebugDatabaseVerify = false
	DebugReplay         = false
	DebugReplayBuilder  = false
	DebugRPCCalls       = false
)
```
